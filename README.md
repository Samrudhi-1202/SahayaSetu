# 🤝 SahayaSetu | ಸಹಾಯಸೇತು

### Connecting Kannada Learning with Community Support

SahayaSetu is a community-support platform that connects people who need assistance with volunteers while encouraging Kannada language learning.

## 🌟 Problem Statement

Language barriers and limited access to community assistance can make everyday activities difficult. A simple platform is needed to promote Kannada learning and connect people with volunteers.

## 💡 Key Features

- Kannada language learning.
- Submit requests for help.
- Volunteer registration.
- Community help board.
- Area and skill-based volunteer matching.

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Git and GitHub

## ⚙️ Installation and Setup

**1. Clone the repository**
```bash
git clone https://github.com/Samrudhi-1202/SahayaSetu.git
```
**2. Open the project folder**
```bash
cd SahayaSetu
```
**3. Create and activate a virtual environment**
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
**4. Install dependencies**
```bash
pip install streamlit
```
**5. Run the application**
```bash
streamlit run app.py
```
