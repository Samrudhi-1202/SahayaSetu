# 🤝 SahayaSetu | ಸಹಾಯಸೇತು

### Connecting Kannada Learning with Community Support

SahayaSetu is a community-support platform designed to connect people who need assistance with volunteers who are willing to help. It also encourages Kannada learning through simple and accessible language-learning resources.

## 🌟 Problem Statement

Language barriers and limited access to community assistance can make everyday activities difficult for people who need support. There is a need for a simple platform that encourages Kannada learning and connects individuals with community volunteers.

## 💡 Our Solution

SahayaSetu provides a common platform where users can learn basic Kannada, request assistance, register as volunteers and view community help requests.

## ✨ Key Features

- **Kannada Learning:** Learn useful everyday Kannada words and phrases.
- **Request Help:** Submit assistance requests by specifying the category, area and details.
- **Volunteer Registration:** Register as a volunteer by providing your area and skills.
- **Community Help Board:** View submitted requests and their current status.
- **Volunteer Matching:** Identify available volunteers based on the request area and required skill.
- **Bilingual Interface:** Supports English and Kannada content.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Samrudhi-1202/SahayaSetu.git
```

### 2. Open the project folder

```bash
cd SahayaSetu
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

For Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install streamlit
```

### 6. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your browser at:

`http://localhost:8501`
